# Melika Kamalifard — Portfolio

A responsive, static portfolio built with HTML, CSS and JavaScript. No build step, external fonts, tracking or database.

## Preview

Run `python3 -m http.server 4173` in this directory, then open http://localhost:4173.

## Publish with GitHub Pages

Push this directory to the intended repository. In Settings → Pages choose **Deploy from a branch**, the main branch and **/(root)**. All asset paths are relative, so the site works under either a repository path or a custom domain.

## Content

Edit project text in `projects.js`, panel text in `app.js`, and homepage/contact details in `index.html`. Visual styling is in `styles.css`. Images are from Melika's supplied portfolio.

The layout takes inspiration from the six-tile navigation and expandable panels of https://github.com/bohdanaTyshchenko/portfolio-2026. The implementation is independently written; no source code or personal assets from that repository are included.

Project/channel metrics are self-reported portfolio outcomes. The Snapp Barcode figure is 300+ leads in the first week after launch. Pakshoma is presented as campaign ideation and execution-team participation, without benchmark performance claims.
